# ⚡ Zoro Fix — Premium Productivity & Task Management

**Zoro Fix** is a modern, responsive productivity dashboard designed to help users organize tasks, manage priorities, track progress, and stay focused through a clean and intuitive interface.

Built using **HTML, CSS, and JavaScript**, the project combines practical task management features with a premium UI, interactive components, and browser-based data persistence.

## ✨ Features

- 📋 **Smart Task Management** — Create, edit, delete, and organize tasks.
- 🎯 **Task Priorities** — Set High, Medium, and Low priority levels.
- 🗂️ **Category Filters** — Organize tasks into Study, Work, and Personal.
- 🔎 **Search & Filtering** — Quickly find tasks by title, status, category, or priority.
- 📅 **Deadline Tracking** — Set deadlines and identify overdue tasks.
- 📊 **Progress Dashboard** — Track total tasks, completed tasks, ongoing work, and overdue items.
- ⏱️ **Pomodoro Focus Timer** — Use focus sessions and breaks to improve productivity.
- 🌙 **Dark & Light Themes** — Switch between comfortable visual themes.
- 💾 **Local Storage** — Keep tasks saved in your browser between visits.
- 📤 **JSON Export** — Export your tasks for backup or portability.
- 📱 **Responsive Design** — Adapt the interface to desktop, tablet, and mobile screens.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🎯 Project Goal

The goal of Zoro Fix is to make everyday productivity simpler by bringing task organization, progress tracking, and focused work into one convenient dashboard.

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or run it using the Live Server extension.
4. Start adding tasks and organizing your workflow.
